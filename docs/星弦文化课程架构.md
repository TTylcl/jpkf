# 星弦文化科技有限公司 — 课程架构文档

> 版本 v1.0 | 2026/07/04 | 基于 agent_system 数据库 & 知识库整理

## 一、机构概览

星弦文化科技有限公司成立于 2010 年，专注音乐教育。旗下 3 个直营校区，50+ 教师（35 位全职，15 位兼职），年均学员 2000+ 人。40% 教师拥有硕士以上学历，8 人具备海外留学背景，平均教龄 6.5 年。

**课程模块四大类：**
- 技能课（器乐 / 声乐）
- 素养课（乐理 / 视唱练耳）
- 实践课（乐队合奏 / 音乐制作）
- 拓展课（考级冲刺 / 音乐剧）

## 二、课程体系

### 2.1 儿童音乐启蒙（4-6 岁）

| 项目 | 内容 |
|------|------|
| 形式 | 小组课（6-8 人） |
| 时长 | 45 分钟 / 周 |
| 课次 | 16 节 / 期 |
| 内容 | 节奏训练、音高感知、简单乐器体验 |
| 目标 | 建立音乐兴趣，过渡到器乐专项 |

### 2.2 器乐专项（7 岁以上）

一对一授课，60 分钟 / 周，三级进阶：

| 级别 | 课时 | 目标 |
|------|------|------|
| 初级 | 36 节 / 年 | 基础技法，CMA 考级 1-3 级 |
| 中级 | 36 节 / 年 | 曲目扩充，CMA 考级 4-6 级 |
| 高级 | 36 节 / 年 | 演奏级，CMA 考级 7-9 级 |

**主开乐器：** 钢琴、吉他、小提琴

### 2.3 架子鼓专项

四级体系，配套自主教材《星弦架子鼓启蒙教程》《星弦节奏训练手册》：

| 级别 | 名称 | 年龄 | 课时 | 目标 |
|------|------|------|------|------|
| L1 | 节奏启蒙 | 4-6 岁 | 16 节 | 演奏 2-3 首简易儿歌 |
| L2 | 基础技巧 | 7-12 岁 | 36 节 | CMA 考级 1-3 级 |
| L3 | 进阶提升 | 13-18 岁 | 60 节 | CMA 考级 4-6 级 |
| L4 | 专业研修 | 16 岁以上 | 100 节 | CMA 考级 7-9 级 |

**内部段位体系（与 CMA 对应）：**

```
青铜鼓手 → CMA 1-2 级
白银鼓手 → CMA 3-4 级
黄金鼓手 → CMA 5-6 级
铂金鼓手 → CMA 7-8 级
钻石鼓手 → CMA 9 级
```

**硬件设备：** Pearl / TAMA 专业套鼓、双踩系统、电子鼓练习房、哑鼓垫。伴奏曲库：启蒙 50 首 / 基础 100 首 / 进阶 80 首 / 专业 60 首。

### 2.4 声乐训练

| 课程 | 年龄 | 形式 |
|------|------|------|
| 童声演唱 | 7-12 岁 | 小组课 + 一对一 |
| 成人声乐 | 13 岁以上 | 一对一 |
| 合唱团 | 全年龄 | 集体排练 |

### 2.5 音乐理论

- 音乐基础（乐理入门）
- 视唱练耳
- 作曲与编曲

### 2.6 特色课程

- 音乐制作（编曲 / 录音）
- 乐队合奏
- 音乐剧表演
- 考级冲刺（CMA 中国音乐家协会官方考点，ISO9001 认证）

## 三、课程类型枚举

系统通过 `course_type` 字段区分三类课程：

| 枚举值 | 中文名 | 说明 |
|--------|--------|------|
| `REGULAR` | 正课 | 常规学期课程 |
| `TRIAL` | 体验课 | 试听课，不可退费 |
| `SUMMER` | 暑假课 | 暑期专项课程 |

课程状态：`1` = 上架 / `0` = 下架。

## 四、教师与课程的关联

```
Course.teacher_id  ──FK──►  User (user_type=TEACHER)
Course.teacher_name          ← 冗余字段，避免 JOIN
```

- 每门课指定一名主讲教师
- Course 模型通过 `teacher` relationship 可获取教师完整信息
- 教师模型通过 `teacher_courses` 反向获取所授课程列表

## 五、学生选课模型

```
StudentCourse (student_courses 表)
  ├── student_id  ──FK──►  User (user_type=STUDENT)
  ├── course_id   ──FK──►  Course
  ├── status      (active / dropped / completed)
  ├── purchased_lessons  购买课时
  └── remaining_lessons  剩余课时
```

**学生生命周期：**

```
报名 (active) ──┬── 正常在读
                ├── 退课 (dropped) ── 可重新激活
                └── 结课 (completed)
```

唯一约束：同一学生 + 同一课程，活跃态只能有一条记录。

## 六、排课模型

### 6.1 正式排课（schedule 表）

```
Schedule
  ├── course_id   ──FK──►  Course
  ├── teacher_id  ──FK──►  User (教师)
  ├── day_of_week  1=周一 .. 7=周日
  ├── start_time / end_time  上课时段
  ├── classroom   教室
  └── status      1=生效 / 0=停用
```

同一教师同一时段有**时间冲突检测**，不允许重叠排课。

### 6.2 预排课流程（pre_schedule 表）

家长提交预约 → 老师审核 → 自动生成正式排课:

```
家长                   老师/教务
  │                      │
  ├─ submit_pre_schedule ─┤
  │  指定学生、课程、       │
  │  期望时间、期望教师     │
  │                      │
  │                   get_pending_reviews
  │                      │
  │                  review_pre_schedule
  │                      ├─ approve → 自动创建 Schedule
  │                      │          → 自动创建 StudentCourse（选课）
  │                      │          → 时间冲突检测
  │                      └─ reject  → 记录拒绝原因
```

## 七、家长-学生关联

```
ParentStudent (parent_student 表)
  ├── parent_id   ──FK──►  User (user_type=PARENT)
  ├── student_id  ──FK──►  User (user_type=STUDENT)
  └── relation    (father / mother / guardian)
```

一个家长可绑定多个学生，一个学生可有多个家长。家长查课/查排课前需验证绑定关系（403 拦截）。

---

## 八、查询链路：从家长到排课

```
家长 ID
  └─ ParentStudent ─► student_id
      └─ StudentCourse ─► course_id
          └─ Schedule ─► day_of_week, start_time, end_time, classroom
          └─ Course ─► course_name, teacher_name
```

`ScheduleQueryService` 提供两条路径：
- **学生路径**（有 student_id / parent_id）：完整 JOIN 带回学生姓名
- **非学生路径**（仅 teacher_id / course_id）：不 JOIN StudentCourse，避免行膨胀

## 九、课程定价与退费

### 9.1 定价

课程价格存储在 `course_info.price` 字段（Numeric 10,2），由教务后台管理。LLM 被明确要求从数据库查询价格，不依赖 RAG 文档。

### 9.2 退费规则

| 时间节点 | 退款比例 |
|----------|----------|
| 开课前 7 天以上 | 全额（扣除材料费） |
| 开课前 3-7 天 | 80% |
| 开课前 72 小时内 | 50% |
| 第 1 节课后 24 小时内 | 剩余课时 70% |
| 第 2 节课后（个人原因） | 不退费 |
| 机构原因 | 全额退款或等价转课 |
| 健康原因（长期） | 剩余课时 90% |
| 搬家（10km 以上） | 剩余课时 85% |

处理时效：审核 3-5 工作日，退款到账 7-15 工作日。体验课不可退。
